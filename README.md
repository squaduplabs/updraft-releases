# UpDraft 🔥

Write the whole Slack thread first. Send it in one go.

UpDraft is a small Mac app for people who think in threads. Write the opening message and every reply in one plain
text document, see it exactly as Slack will show it, pick a channel or person, and send. The messages go out in order,
as you.

- **One document, the whole thread.** A line of `---` starts the next reply. No boxes, no clicking between messages.
- **What you see is what lands.** The preview is Slack's own thread view, light or dark, with mentions, emoji, code
  blocks and screenshots.
- **Slack's formatting, as you'd type it.** `*bold*`, `_italic_`, lists, quotes and code, with `@`, `#` and `:`
  autocomplete.
- **Sends as you, in order.** If something stops it partway, it picks up where it left off.
- **Works with your AI agent.** Claude Code, Cursor and other MCP apps can draft and send threads through it.
- **Keyboard first.** ⌘K picks where it goes, ⌘↩ splits a message, ⌘⇧↩ sends.

Your drafts stay on your Mac, and UpDraft only posts to Slack when you send.
